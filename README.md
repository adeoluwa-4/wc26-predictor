# World Cup 2026 Predictor

This project uses past soccer results to predict World Cup 2026 matches and simulate the full 48 team tournament. The [live dashboard](https://adeoluwa-4-wc26-predictor-streamlit-app-awcr9s.streamlit.app) shows match chances, group results, knockout paths, team advancement odds, and possible champions.

I built the data pipeline, CatBoost models, tournament rules, repeated simulations, automated updates, tests, and Streamlit dashboard in Python. The predictions are estimates based on historical data, not guaranteed results.

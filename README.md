# World Cup 2026 Predictor

## What it does

This project uses past soccer results to predict World Cup 2026 matches and simulate the full 48 team tournament. The dashboard shows match chances, group results, knockout paths, team advancement odds, and possible champions.

## What I built

I built the data pipeline, CatBoost models, tournament rules, repeated simulations, automated updates, tests, and Streamlit dashboard in Python. The predictions are estimates, not guaranteed results.
